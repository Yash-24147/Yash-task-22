About

This is a simple AI Workspace Landing Page. It helps teams manage their tasks and work together.

Technologies Used

HTML

Tailwind CSS

JavaScript

Features

Sticky navigation bar

Hero section with heading and description

Get AI free and Request a demo buttons

Dashboard preview

Three floating information cards

Fixed chat button

Responsive layout

Mobile navigation menu

How to Run

Create a folder named Project Workspace.

Add index.html, style.css and script.js files.

Keep all files in the same folder.

Open index.html in your browser.

Make sure you have an internet connection for Tailwind CSS CDN.
